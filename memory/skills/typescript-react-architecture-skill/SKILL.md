# مهارت معماری TypeScript و React استاندارد جهانی (TypeScript & React Architecture Skill)

## استانداردهای کدنویسی بدون نقص
1. **تایپ‌پذیری کامل (`tsc --noEmit` بدون خطا):** هیچ `any` بی‌پشتوانه یا متغیر استفاده‌نشده‌ای در کامپوننت‌ها باقی نمی‌ماند. تمام رویدادها، پروپ‌ها و ساختارهای داده از `src/types/dental.ts` ایمپورت می‌شوند.
2. **انضباط دیالوگ‌ها و پورتال (`ViewportModalPortal` + `useEscapeKey`):** تمام مدال‌ها باید با `role="dialog"` و `aria-modal="true"` رندر شوند، در برابر بستن تصادفی با کلید `Escape` محافظت شوند و در صفحه اصلی قفل اسکرول افقی را رعایت کنند.
3. **صراحت دکمه‌ها (`type="button"`):** تمامی دکمه‌های غیرفرم باید دارای `type="button"` باشند تا هرگز باعث ارسال ناخواسته فرم نشوند.
4. **الگوی تایید دو مرحله‌ای (`ArmedActionButton`):** عملیات حساس مانند لغو نوبت، عدم حضور، تغییر وضعیت روی یونیت، اتمام کار، حذف چک یا تایید شیفت صف با لمس اول مسلح و با لمس دوم اجرا می‌شوند تا خطای لمس تصادفی منشی به صفر برسد.
5. **مقیاس‌پذیری و سرعت رندر:** استفاده از `useMemo` برای فیلترها و شمارش‌های روزانه و استفاده از `toPersianDigits` / `toEnglishDigits` جهت تطبیق فوری جستجو و مرتب‌سازی ارقام فارسی و انگلیسی.
