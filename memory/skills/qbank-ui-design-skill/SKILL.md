# مهارت طراحی رابط کیوبانک و iOS 27 (QBank UI Design Skill)

## قوانین قفل‌شده بصری (`noDarkBackgrounds: true`)
1. **ممنوعیت مطلق پس‌زمینه تیره/مشکی در UI:** هرگونه `bg-slate-900`، `bg-slate-950` یا `bg-[#0f1b13]` در کارت‌ها، دکمه‌ها و هدرها ممنوع است (به‌جز اوورلی مدال `fixed inset-0` و بوم تصویر رادیولوژی). تمام پنل‌ها باید روشن، زنده و با کنتراست خوانا روی پس‌زمینه سفید/شیشه‌ای باشند.
2. **کاشی‌های منعطف و گوشه منحنی:** داشبورد از کاشی‌های با انحنای اختصاصی در گوشه (نه مستطیل تیز)، انیمیشن فشاری نرم شبیه کلید کیبورد هنگام لمس (`active:scale-95`) و گرید پاسخگو (`grid-template-columns: repeat(auto-fill, minmax(280px, 1fr))` در ریسپانسیو و کاشی‌های کشیده بدون پرش) بهره می‌برد.
3. **نوار چیپ افقی چندرنگ بدون تکرار (`chipThemes.ts`):** هر ماژول در بالای صفحه دارای چیپ‌بار افقی راست‌به‌چپ است که تمام زیربخش‌های همان ماژول را با رنگ‌بندی متمایز و سرچ ذره‌بینی بازشونده ارائه می‌دهد.
4. **استاندارد لمس موبایل و حریم امن (Safe Area):** حداقل ابعاد لمس دکمه‌ها `44px` (`min-h-[44px]`)، استفاده از `pb-[max(0.875rem,env(safe-area-inset-bottom))]` در شیت‌های تمام‌صفحه موبایل و ممنوعیت اسکرول افقی صفحه (`w-full max-w-full min-w-0 overflow-x-hidden`).
5. **ممنوعیت دیالوگ مسدودکننده مرورگر و تله‌متری:** استفاده از `window.alert`، `window.confirm`، `window.open` و نمایش بج‌های فنی/شناسه سیستمی روی کارت‌های بالینی ممنوع است.
