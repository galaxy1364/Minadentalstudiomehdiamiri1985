# مهارت همگام‌سازی بلادرنگ، PWA و نوتیفیکیشن گوشی (Offline PWA & Sync Skill)

## الزامات پایداری داده و پلتفرم‌ها
1. **پایداری ۵۰۰ هزار پرونده و جلوگیری از پاک شدن داده:** هرگونه ثبت بیمار، نوبت، درمان یا چک در لایه ذخیره‌سازی لوکال (`IndexedDB` / `localStorage` مقاوم) + کانال همگام‌سازی فوری بین پلتفرم‌های مجاز (منشی / پزشک / مدیر) ثبت و بلافاصله منعکس می‌شود.
2. **بک‌آپ‌گیری خودکار و دستی (لوکال / ابری / گوگل‌درایو):** پشتیبانی از خروجی JSON/CSV با زمان‌بندی دلخواه و بازیابی مطمئن بدون حذف اطلاعات قبلی.
3. **نوتیفیکیشن واقعی گوشی (Web Push / Service Worker / Vibration):**
   - تمام ماژول‌ها (نوبت‌دهی، چک، اقساط، لابراتوار، ایمپلنت، کسری انبار) از کامپوننت مشترک `ReminderOptionPicker` و سرویس `reminderNotificationService` استفاده می‌کنند.
   - پشتیبانی از اعلان فوری، تعویق (Snooze) و یادآوری زمان‌بندی‌شده پیش از موعد (مثلاً ۱ ساعت قبل، ۱ روز قبل، ۳ روز قبل).
4. **پیکربندی کامل iOS 27 WebClip / IPA و Android APK / PWA:** رعایت `manifest`، آیکون بنفش مینادنتال، متا تگ‌های `apple-mobile-web-app-capable` و جلوگیری از برش در ناچ آیفون.
