# مهارت حافظه فعال و تداوم معماری مینادنتال (Memory Continuity Skill)

## قوانین قفل‌شده غیرقابل نقض
1. **واحدهای استاندارد کلینیک:** نام یونیت‌ها همواره `یونیت آبی`، `یونیت زرد` و `یونیت جراحی` است (هرگونه نام قدیمی از طریق `normalizeClinicUnitName` مپ می‌شود).
2. **قانون رنگ روشن بالینی (`noDarkBackgrounds: true`):** هیچ کارت، بج یا دکمه در رابط کاربری مطب نباید پس‌زمینه مشکی یا سرمه‌ای تیره (`bg-slate-900`, `bg-slate-950`, `bg-slate-800`, `bg-[#0f1b13]`) داشته باشد.
3. **پالایش تلمتری از رابط کاربری:** شناسه‌های رهگیری (`MD-*-1405-*`, `MD-TST-*`) صرفاً در `/memory/` و گزارش‌های تست اجرا می‌شوند و روی کارت‌های بالینی پرسنل/بیمار نمایش داده نمی‌شوند.
4. **تفکیک دقیق مالی و پورسانت (`10^-6`):** کارکرد پزشکان از سهم کارکرد منهای هزینه لابراتوار محاسبه می‌شود و پرداخت‌ها، چک‌های صیادی و اقساط متعلق به حساب مطب/مدیر کلینیک (`دکتر مهدی امیری`) است.
5. **به‌روزرسانی اجباری پس از هر تغییر:** بعد از اتمام هر ارتقاء ماژول، باید `npm run test:all` اجرا شده و `STUDIO_MEMORY_BANK.json` و `TEST_AUDIT_LEDGER.json` همگام شوند.
